# ClearFlow — Financial Product Welcome Page

> **Prompt 01 — Explain the Product to a New Visitor**  
> *A person visits a financial website for the first time. They leave because they cannot quickly understand what it offers or whether it is relevant to them. Build one welcome page that explains what the product does, who it helps, and what the visitor can do next.*

## How This Prototype Solves It

1. **What it does (5-Second Clarity):** Plain-English hero headline (*"Know what’s safe to spend today—without spreadsheets"*) backed by a 3-step visual breakdown and zero financial jargon.
2. **Who it helps (Self-Identification):** Interactive persona switcher (`Freelancer`, `Salaried`, `Couple`) in the hero that updates a live **Safe to Spend** preview card on the spot, paired with dedicated persona cards below.
3. **What to do next (Low-Friction Action):** Clear primary call-to-action (**Try Interactive Demo**) that opens an instant, no-signup **Safe to Spend Calculator**, alongside transparent trust signals (read-only access, 256-bit encryption).

## Project Structure

- `index.html` — Semantic single-page structure + interactive calculator modal
- `styles.css` — Responsive layout, typography, and component styles
- `script.js` — Persona tab switcher and live daily budget calculator
- `.nojekyll` — Tells GitHub Pages to serve static files directly without Jekyll processing

## Run Locally

Open `index.html` directly in any web browser—no build step or dependencies required.
